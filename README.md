# GPT 文本重点与情绪高峰提取网站（新手可执行版）

这是一个**不用安装复杂依赖**的网页小工具。你只需要把 GPT 的一段文字粘贴进去，点一下按钮，就能看到：
- 自动提取的 1-3 条重点；
- 在原文中做下划线/高亮后的结果。

---

## 你可以用哪种方式打开？

### 方式 A（最简单，推荐先试）
直接双击 `index.html` 用浏览器打开。

### 方式 B（更稳定，推荐长期使用）
在项目目录启动本地静态服务器，再用浏览器访问 `http://localhost:4173`。

---

## 方式 A：直接双击打开（3 步）

1. 打开项目文件夹，确认你能看到这 4 个文件：
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`
2. 双击 `index.html`。
3. 浏览器打开后：
   - 在“输入文本”粘贴 GPT 文本；
   - 点击“提取重点”；
   - 页面下方会出现“1-3 个重点”和“标注后的文本”。

> 如果双击后样式错乱或按钮没反应，请改用下面的“方式 B”。

---

## 方式 B：命令行启动（详细到每一步）

## 1) 打开终端

- **Windows**：按 `Win + R`，输入 `cmd`，回车。  
- **macOS**：打开“终端（Terminal）”。  
- **Linux**：打开“终端”。

## 2) 切换到项目目录

假设你的项目在：

```bash
cd /你的项目路径/emotion-extraction-dear-
```

不知道路径时可以：
- 在文件管理器里打开该目录；
- 复制地址栏路径；
- 粘贴到 `cd` 后面。

## 3) 启动本地服务器

输入：

```bash
python3 -m http.server 4173
```

如果你是 Windows 且 `python3` 不可用，试：

```bash
python -m http.server 4173
```

看到类似下面输出，就表示成功：

```text
Serving HTTP on 0.0.0.0 port 4173 ...
```

## 4) 在浏览器打开网页

访问：

```text
http://localhost:4173
```

## 5) 开始使用

1. 粘贴 GPT 文本到输入框；
2. 点击“提取重点”；
3. 查看：
   - 上方列表：提取出的 1-3 个重点句；
   - 下方区域：带高亮/下划线的原文。

## 6) 关闭服务器

回到终端，按 `Ctrl + C` 停止。

## 常见问题（按症状排查）

### Q1：浏览器打不开 `http://localhost:4173`
- 先确认终端窗口还在运行，没有被关闭；
- 确认命令没有报错；
- 换一个端口再试：
  ```bash
  python3 -m http.server 8080
  ```
  然后访问 `http://localhost:8080`。

### Q2：提示 `python3: command not found`
- Windows 尝试改用：
  ```bash
  python -m http.server 4173
  ```
- 若仍不行，说明本机未安装 Python，请先安装 Python 3。

### Q3：点击“提取重点”没显示结果
- 先确认输入框里有文字；
- 尝试点“填充示例”验证功能是否正常；
- 刷新页面后重试。

## 功能说明（你会看到什么）

- 页面会从输入文本中自动挑选 1-3 条“更值得强调/情绪更强”的句子；
- 重点句会用高亮或下划线标出；
- 一些强调词（例如“必须”“最重要”“非常”等）也会被下划线标注。
